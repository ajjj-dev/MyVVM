MyVVM

A sample Android application built using Kotlin to learn and practice modern Android development with MVVM and Clean Architecture principles.

Features
MVVM Architecture
Clean Architecture
Room Database
ViewModel & LiveData
Kotlin Coroutines
Repository Pattern
Modern Android Development Practices
Scalable Project Structure
🛠 Tech Stack
Kotlin
Android Jetpack
Room Database
ViewModel
LiveData
Coroutines
RecyclerView / Jetpack Compose (update based on your project)
Material Design

Purpose of the Project

This project was created for:
Learning MVVM Architecture
Understanding Clean Architecture layers
Practicing Android app development using Kotlin
Improving code maintainability and scalability
Exploring modern Jetpack libraries

Getting Started
git clone https://github.com/ajjj-dev/MyVVM.git

Open the project in Android Studio and run the app.
